# Screenshots

Drop images here with the filenames below and they'll automatically appear in
the main [README](../../README.md#screenshots) — it already references these
exact paths.

| Filename | Page/flow |
|---|---|
| `homepage.png` | Homepage (hero, featured pieces) |
| `collections.png` | Collections grid (filter/search/sort) |
| `product-page.png` | Product detail page |
| `cart.png` | Cart page |
| `checkout.png` | Checkout page (address + coupon + order summary) |
| `wishlist.png` | Wishlist page |
| `profile.png` | Customer profile / account page |
| `orders.png` | Customer order history |
| `admin-dashboard.png` | Admin dashboard overview |
| `admin-products.png` | Admin product management |
| `admin-coupons.png` | Admin coupon management |
| `mobile.png` | Any page at mobile width, to show responsiveness |

Recommended: 1280px-wide PNG or WebP screenshots of the light theme, browser
chrome cropped out. Keep individual files under ~500KB (compress with
`pngquant`/`squoosh` if needed) so the repo stays lightweight.
